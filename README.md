## 🎮 Highlights & Features

- **Flagship Games Showcase**:
  - **[AZYMAR Playground](https://azymar.me)** — Instant-play web arcade ecosystem with 13+ live titles.
  - **Murugan: Surasamharam** — Third-person mythological Action RPG built with Unreal Engine 5.
  - **VR Surgical Simulation** — 90Hz sterile medical operating theater with 6DoF hand tracking.
  - **Verity Systems** — Zero-trust cryptographic research and ledger anchoring platform.
- **Interactive 3D Elements**:
  - Interactive WebGL scenes powered by `@react-three/fiber` and `@react-three/drei`.
  - Live interactive 3D Doctor rig viewer for spatial medical XR.
- **Interactive In-Browser Mini-Game**:
  - 30-second reflex arcade mini-game built with canvas.
- **Hidden Admin Panel**:
  - Discovered via secret key combo `Ctrl + Shift + A` (or `Cmd + Shift + A`).
  - Interactive box view for contact messages, unread counters, search filters, and status toggles.
- **Careers & Guild Hiring**:
  - Roles for *Game Programmer*, *3D Animator*, *Game Designer*, and *Level Designer*.
- **Theming & Accessibility**:
  - Smooth Lenis scrolling, custom interactive cursor, and full dark/light theme support.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.17+ (or v20+)
- **npm** or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/azymar03-ux/AZYMAR-PORTFOLIO.git

# Enter project directory
cd AZYMAR-PORTFOLIO

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
